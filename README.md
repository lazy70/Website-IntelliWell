# IntelliWell Corporate Website

Responsive static corporate website for the IntelliWell engineering ecosystem.

## Included
- IntelliWell Analytics and Production LiftLab product descriptions and launch links
- Petroleum engineering simulation, data science, AI and ML technology roadmap
- Research methodology and transparency about features in development
- Responsive layout, accessible mobile navigation, SEO metadata

## Deployment
Connect this repository to Netlify. No build command is required; publish directory is the repository root (`.`). Deploy to a temporary Netlify URL before changing existing IntelliWell DNS.

## Notes
AI/ML items are identified as research directions, not validated production features. Existing applications remain at https://intelliwell.me/ and https://productionliftlab.netlify.app/ .
